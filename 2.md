* Virtualización: Técnica que permite crear versiones virtuales de recursos físicos, como servidores o sistemas operativos.

* Hipervisor: Software que crea y gestiona máquinas virtuales, permitiendo que varios sistemas operativos funcionen en un mismo hardware.

* Máquina virtual (VM): Entorno virtual que actúa como un ordenador independiente dentro de un equipo físico.

* Host: El equipo físico donde se ejecutan las máquinas virtuales.

* Guest: Sistema operativo o aplicación que corre dentro de una máquina virtual.

* Virtualización de servidores: Ejecutar múltiples servidores virtuales en un solo servidor físico.

* Virtualización de escritorio: Permite que un escritorio completo corra en un servidor y sea accesible remotamente.
